# Interactive learning activities

Self-contained activities for embedding in an online course. One folder per activity:
a single `index.html` with no dependencies, no network calls, no storage and no
analytics.

Built to be served over HTTPS inside an iframe, with no framebusting, no personal data,
no login and no score written back to the host platform. Each fits a 320x480 portrait
viewport with no page scrolling, is operable by keyboard alone, and uses text at
14px/18px minimum with contrast measured at 15.7:1 or better.
